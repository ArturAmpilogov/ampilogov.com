# Ампилоговы / Анпилоговы / Ампиловы / Анпиловы / Анфилоговы

Книга об истории имени, фамилии и разных родов Ампилоговых / Анпилоговых / Ампиловых / Анпиловых / Анфилоговых. Публичное повествование охватывает события по 1950 год включительно. Главы связаны с каталогом документов, профилями и картой.

## Главный принцип

Источники показывают несколько географически и хронологически раздельных групп носителей сходной фамилии. Сходство написания не доказывает родство, а предполагаемый маршрут переселения не становится фактом без документа о конкретном человеке.

Сведения о современной прямой семейной линии пользователя пока в книгу не включаются.

## Редакционное правило

Текст не соединяет однофамильцев в одно дерево без документа. Каждая реконструкция либо опирается на прямо названное родство, либо явно помечена как гипотеза. Проверенные сведения сопровождаются карточкой документа и ссылкой на изображение. Сканы из `public/archive/evidence/` и `data/genealogy/evidence-private/` хранятся в приватном Vercel Blob вне Git; находки без проверенного изображения сохраняют свой исследовательский статус.
