# Ампилоговы / Анпилоговы / Ампиловы / Анпиловы / Анфилоговы

Рабочая книга об истории имени, фамилии и разных родов Ампилоговых / Анпилоговых / Ампиловых / Анпиловых / Анфилоговых. Репозиторий хранит исследовательский текст, реестр людей, карточки документов и фотокопии источников до появления интерфейса интерактивной книги.

## Главный принцип

Источники показывают несколько географически и хронологически раздельных групп носителей сходной фамилии. Сходство написания не доказывает родство, а предполагаемый маршрут переселения не становится фактом без документа о конкретном человеке.

Сведения о современной прямой семейной линии пользователя пока в книгу не включаются.

## Редакционное правило

Текст не соединяет однофамильцев в одно дерево без документа. Каждая реконструкция либо опирается на прямо названное родство, либо явно помечена как гипотеза. Подтверждённый факт получает карточку документа и фотокопию в Git; находка без изображения остаётся в очереди `leads/`.
