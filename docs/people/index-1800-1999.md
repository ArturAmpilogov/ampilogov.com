# Общий реестр людей, 1800–1999

В этот список попадают только люди, подтверждённые карточкой документа `R####` и фотокопией в `evidence/`. Производные индексы без изображения находятся в [очереди находок](../leads/1800-1999.md).

| ID | Имя в нормализованной форме | Варианты в документах | Годы | Места | Записи | Профиль | Статус |
|---|---|---|---|---|---|---|---|

## Правила сортировки

1. По самому раннему подтверждённому году.
2. Внутри года — по фамилии и имени.
3. Если два упоминания ещё не отождествлены, они получают разные ID.

## Статусы

- `single-record` — одно подтверждённое упоминание;
- `multi-record` — несколько документов уверенно относятся к одному человеку;
- `identity-review` — возможное объединение с другим человеком проверяется;
- `migration-evidence` — человек участвует в доказанном маршруте;
- `private` — профиль существует локально, но не публикуется.
