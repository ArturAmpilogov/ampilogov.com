# Люди и профили

## Почему нужен гибрид

Один огромный список удобен для обзора, но плохо подходит для доказательств. Отдельный профиль на каждое случайное упоминание создаст сотни почти пустых файлов. Поэтому используются три уровня:

1. `people/index-1800-1999.md` — общий список всех подтверждённых людей;
2. `people/profiles/` — отдельные профили только для людей с несколькими документами, вариантами имени или спорным отождествлением;
3. `records/` — карточки первичных документов, на которых основаны все факты.

## Идентификаторы людей

Каждому человеку присваивается стабильный код `P####`. Код не кодирует дату, место или фамилию: эти сведения могут уточниться, а идентификатор должен остаться прежним.

Новый человек появляется в реестре только после добавления хотя бы одной подтверждённой карточки `R####` с фотокопией.

## Когда создавать отдельный профиль

Профиль создаётся, если:

- есть два и более документа;
- фамилия или имя записаны в разных формах;
- есть одноимённые люди, которых важно различать;
- документально названы супруги, дети или родители;
- человек участвует в доказанном маршруте переселения.

Для одиночного упоминания достаточно строки в общем реестре и карточки документа.

## Запрещённые сокращения исследования

- не создавать родство только из совпадения отчества;
- не сливать одноимённых людей;
- не переносить дату или место из чужого дерева без фотокопии;
- не считать индекс FamilySearch фотокопией;
- не добавлять живущих людей без отдельного решения о публикации.
