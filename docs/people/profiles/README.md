# Профили людей

Имя файла: `P####-short-slug.md`.

Профиль содержит:

- нормализованное имя;
- все буквальные варианты имени и фамилии;
- только подтверждённые даты и места;
- список карточек документов;
- прямо названные отношения;
- отдельный блок спорных отождествлений;
- ссылки на миграционные досье.

Фактическая транскрипция и фотокопия хранятся не в профиле, а в соответствующей карточке `records/`.
