# Фотокопии источников

Здесь хранятся фотокопии, на которых основаны карточки `records/`.

## Структура

```text
evidence/
  rgada/
    f181-op2-d120/
      0060.jpg
  publications/
    ruslang/
      etymology-1971/
        13-nikonov.pdf
        pages/
          0263.jpg
  dazo/
  gark/
  gia-ko/
```

## Правила

1. Оригинальный скачанный файл сохраняется без обрезки и улучшения.
2. Имя каталога содержит архив, фонд, опись и дело.
3. Имя файла сохраняет номер кадра или листа.
4. Кадр должен включать контекст страницы; увеличенные фрагменты можно положить рядом с суффиксом `-crop`, но они не заменяют оригинал.
5. Для каждой фотокопии первичного документа существует хотя бы одна карточка `R####`.
6. Научные публикации могут быть приложены непосредственно к записи в реестре источников; для ключевой страницы рядом сохраняется отдельное изображение.
7. В карточке или реестре источников указываются URL получения, архивный шифр либо библиографическое описание, страница и дата скачивания.
8. Индекс или карточка сайта без изображения не считается фотокопией.

## Удалённые просмотрщики: обязательный комплект

Для Яндекс Архива и других просмотрщиков, которые не отдают исходный файл напрямую,
каждый использованный кадр сохраняется как три самостоятельных изображения:

1. `####-full-view.png` — весь лист или разворот целиком. На изображении остаётся только
   документ: без шапки сайта, панели OCR, кнопок, поисковой выдачи, полос браузера и иных
   элементов интерфейса.
2. `####-header.png` — увеличенная область с заголовком книги, годом, частью и названиями
   граф. Заголовок должен читаться без обращения к OCR сайта.
3. `####-target-entry.png` либо `####-target-entry-document-*.png` — увеличенная точная
   строка с исследуемой фамилией, именами, датой, родством и статусом. Сохраняется достаточно
   соседних строк и граф, чтобы однозначно установить принадлежность текста нужной записи.

Скриншот страницы сайта, поисковой карточки или окна просмотрщика не заменяет ни один из
этих файлов. OCR допустим только как поисковая подсказка и не должен попадать в фотокопию.
Комплект считается проверенным только после визуального просмотра всех трёх изображений и
записи их SHA-256 в соответствующий Record.

## Форматы

- JPEG или PNG для отдельных кадров;
- PDF допустим для целого дела или публикации;
- TIFF сохраняется, если это исходный формат архива;
- производные WebP-файлы для сайта создаются позже и не заменяют оригиналы.

Большие дела при необходимости подключаются через Git LFS, но одиночные метрические кадры и страницы хранятся прямо в Git.
