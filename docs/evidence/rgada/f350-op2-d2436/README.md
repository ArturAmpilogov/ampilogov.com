# РГАДА, ф. 350, оп. 2, д. 2436

Рабочее собрание фотокопий пяти ревизских сказок однодворцев деревни Баздырева Орловского уезда. Дело относится к первой ревизии 1719 года.

## Найденные листы

- л. 367 — Харитон Филипов сын Анпилогов;
- л. 368 — Потап Григорьев сын Анпилогов;
- л. 369 — Гордей Козмин сын Анпилогов;
- л. 370 — Никита Тимофеев сын Анпилогов;
- л. 371 — Фёдор Меркулов сын Антилогов.

Имена выше переданы по опубликованному именным указателю. На каждом из пяти листов найдена соответствующая рукописная ревизская сказка, однако её полная буквальная расшифровка ещё не выполнена.

## Статус чтения

Эти пять карточек пока не являются genealogical Records. Для каждого листа нужно:

1. прочитать всю самостоятельную ревизскую сказку, а не только имя из указателя;
2. сохранить точный кроп всей записи;
3. отделить буквальную расшифровку от современной интерпретации;
4. перечислить всех названных в сказке членов семьи отдельными упоминаниями.

До этого листы остаются карточками источников с оригиналом, точным архивным адресом и проверяемой личностью.
