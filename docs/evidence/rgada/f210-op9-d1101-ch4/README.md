# РГАДА, ф. 210, оп. 9, д. 1101, ч. 4

Рабочая фотография документа со списками белгородских служилых людей,
погибших, раненых и взятых в плен под Конотопом в 1659 году.

Пользовательская расшифровка на ВГД называет **Зинова Онпилогова
(Анпилогова)**. Точный лист не указан. Опубликованная база DomPredkov
подтверждает шифр дела, но не содержит этой фамилии в доступной таблице.

## Статус изображения

Файл `pages/forum-photo-full.jpg` — фотография разворота размером 1936×1936.
Она слишком размыта для надёжной локализации строки, кропа и буквальной
расшифровки. Изображение сохранено как ориентир для заказа архивной копии,
но отдельный genealogical Record по нему не создан.

## Что нужно заказать

1. именной или листовой указатель к части 4;
2. полный лист с записью Зинова;
3. снимок не ниже архивного разрешения;
4. после получения — кроп всей самостоятельной записи и буквальную
   расшифровку без восстановления неразборчивых слов по догадке.
