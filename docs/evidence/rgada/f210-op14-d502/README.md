## Статус чтения

Ни один из трёх листов пока не превращён в genealogical Record. Имена в карточках переданы по указателю, а не по полной буквальной расшифровке рукописи. Перед созданием Records необходимо:

1. завершить локализацию нижней границы записи на л. 67; записи на л. 94 об. и 109 уже локализованы;
2. сохранить отдельный кроп всей строки или блока записи;
3. прочитать строку целиком, не дополняя неразборчивое по догадке;
4. отдельно указать чин, оклад, вооружение и иные сведения, если они действительно читаются.

### Визуальная проверка 21 августа 2026 года

- **л. 67:** запись видна на небольшом отдельном листе, но её формула и границы ещё не прочитаны достаточно уверенно для буквальной расшифровки;
- **л. 94:** снимок тёмный и малоконтрастный; имя установлено по указателю, а не по надёжному чтению всей строки;
- **л. 109:** текст различим лучше, однако на листе несколько записей, и нужный блок ещё не локализован с доказанной точностью.

### Локализация 25 августа 2026 года

- **л. 67:** начало записи Василия Дмитриевича найдено в нижней части кадра 184; полная нижняя граница пока не доказана;
- **л. 94 об.:** запись Алексея Васильевича — третий самостоятельный блок кадра 252, между Томилой Тереховым Тепловым и Самсоном Дмитриевым Онахиным;
- **л. 109:** запись Ивана Васильевича — первый полный самостоятельный блок кадра 312, перед Иваном Семёновым Чюпахиным и двумя Козаковыми.

Для всех трёх мест сохранены точные цветные кропы. Таким образом, прежняя задача «найти нужную строку среди записей листа» решена для л. 94 об. и 109 и частично решена для л. 67. Следующая стадия — палеографическая расшифровка формул оклада, поместья и вооружения.

Поэтому эти три находки остаются карточками источников. Создавать по ним Records до полного чтения строки было бы нарушением правила проекта «одна самостоятельная запись источника — один Record».

Повторная проверка полного дела 25 августа 2026 года не выявила надёжно читаемой формулы прежнего города, перевода или происхождения ни для одного из трёх людей. Это не доказательство отсутствия такой формулы: нужные блоки ещё должны быть локализованы и прочитаны полностью.
