# Карточки документов

Карточка `R####` — единственное место, где формулируется факт из конкретного источника.

## Структура каталогов

Карточки группируются по году документа:

```text
records/
  1596/
    R0001-pavel-terentev-anfilogov.md
  1850/
  1900/
```

Если точный год неизвестен, используется каталог десятилетия: `records/1850s/`.

## Обязательные поля

- ID записи;
- дата и место;
- тип документа;
- архивный шифр;
- люди с их `P####`;
- буквальное написание;
- транскрипция;
- нормализованное извлечение фактов;
- путь к фотокопии;
- что документ доказывает;
- чего документ не доказывает;
- степень уверенности и спорные чтения.

Шаблон находится в [template.md](template.md).
