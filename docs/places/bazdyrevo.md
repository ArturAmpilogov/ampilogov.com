# Баздырево / Боздырево

## Роль в исследовании

Баздырево Корчаковского стана Орловского уезда — один из ключевых топонимов орловского кластера. С ним связаны Анфилоговы в писцовых и служилых материалах конца XVI–XVII веков.

В 1697 году Аким Иванович **Анпилогов** прямо назвал себя бывшим орловским помещиком Боздырева. Это создаёт документальный географический мост к ливенским Щиграм, но ещё не соединяет все более ранние баздыревские семьи с Акимом.

## Варианты написания

- Баздырево;
- Боздырево;
- Боздорево в вторичной транскрипции.

Для архивного поиска нужно проверять все формы.
