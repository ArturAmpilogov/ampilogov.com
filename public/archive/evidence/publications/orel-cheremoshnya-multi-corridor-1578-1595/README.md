# Черемошня раннего Орла: сравнительный фамильный контекст

Фотокопии страниц дореволюционного издания «Писцовые книги Московского государства. Часть I. Отделение 2» (Санкт-Петербург, 1877):

- `tula-1587-1589-print-p1196-kutepov-family-network.png` — Богдан Иванович, Михаил и Матвей Фёдоровичи Кутеповы в Колоденском стане Тульского уезда;
- `tula-1587-1589-print-p1197-kutepov-dedilov-odoev-holdings.png` — продолжение статьи: за Михаилом и Матвеем названо поместье на Дедилове, за Фёдором Юрьевичем Кутеповым — в Одоеве;
- `tula-1587-1589-print-p1220-bredikhin-family-network.png` — Сава Фомин сын Бредихин в Глутенском стане; один из многочисленных тульских домов этой фамилии.

Для орловского сопоставления карточка повторно использует сохранённую печатную с. 885, где в одной Черемошне записаны семья Бредихиных, Иван Аввакумович Кутепов и Филипп Фёдорович Теплов.

Цифровая копия полного издания: <https://archive.org/details/moscha-regia>.

Прямой прежний город установлен только для Филиппа Теплова: Каширская книга сообщает, что он был испомещён в Орле. Совпадения Кутеповых и Бредихиных показывают фамильную среду и многогородовое землевладение, но не доказывают переезд конкретных орловских владельцев из Тулы.
