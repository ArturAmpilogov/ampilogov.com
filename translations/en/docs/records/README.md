# Document Cards

An `R####` card is the only place where a fact from a specific source is formulated.

## Directory Structure

Cards are grouped by the year of the document:

```text
records/
  1596/
    R0001-pavel-terentev-anfilogov.md
  1850/
  1900/
```

If the exact year is unknown, a decade directory is used: `records/1850s/`.

## Required Fields

- record ID;
- date and place;
- type of document;
- archival reference;
- people with their `P####`;
- literal spelling;
- transcription;
- normalised extraction of facts;
- path to the photocopy;
- what the document proves;
- what the document does not prove;
- degree of confidence and disputed readings.

The template is in [template.md](template.md).
