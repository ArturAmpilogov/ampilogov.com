# Person Profiles

File name: `P####-short-slug.md`.

A profile contains:

- the normalised name;
- all literal variants of the first name and surname;
- only confirmed dates and places;
- a list of document cards;
- explicitly stated relationships;
- a separate block for disputed identifications;
- links to migration dossiers.

The actual transcription and photocopy are kept not in the profile but in the corresponding `records/` card.
