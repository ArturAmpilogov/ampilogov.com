covers books 61–72, and book 68 in it is dated 7157/1648–49. Book 61

book 61 there were no hits. The line needs to be rechecked at the source.

website. So a folio for file 6д-169 cannot be obtained via the alphabetical indexes — only by ordering
from the archive. Kozlov, incidentally, is also a new town for the project.

12-1628 (1697) from the previous batch, the Oboyan line gets three points after the
desyatnya (service register) of 1651.

## What Needs to Be Downloaded

My container is not allowed through to `rgada.info` — the host is not on the allowlist, and the
local shell has no network either. The downloading will have to be done in your browser; I will go through the
images as soon as they are in the repository.

The letters **А** and **О** are needed in three volumes:

```
http://rgada.info/opisi/210-ukaz_126/XXXX.jpg   ← книги от 111; нужна книга 121
http://rgada.info/opisi/210-ukaz_127/XXXX.jpg   ← книги 129—133; нужны 130, 131, 133
http://rgada.info/opisi/210-ukaz_132/XXXX.jpg   ← книги от 170; нужны 170, 177, 180
```

(Volume 126: books from 111, book 121 needed; volume 127: books 129–133, 130, 131 and 133 needed; volume 132: books from 170, 170, 177 and 180 needed.)

The procedure is the same as in `alfavity-belgorodskogo-stola.md`: scan 0002 or
0003 of each volume holds a table of contents "letter → folio numbers"; from it one finds the
spreads for the letters А and О, and then only the surname column is read.

Plus inventory pages, to identify the documents:

```
опись 6,  дело 97    — заголовок раздаточной книги 1679 года
опись 6е, дело 25    — заголовок именного списка 1678 года
опись 6ж, дело 134   — заголовок раздаточной книги 1680 года
опись 4,  дело 254   — смотренный список Хотмыжска 1655 года
опись 13, дело 571   — описи 13 в проекте нет вовсе
опись 12, дела 78, 331, 601, 630, 985, 1169, 1528, 1698
```

(Inventory 6, file 97 — heading of the distribution book of 1679; inventory 6е, file 25 — heading of the name list of 1678; inventory 6ж, file 134 — heading of the distribution book of 1680; inventory 4, file 254 — the Khotmyzhsk muster roll of 1655; inventory 13, file 571 — inventory 13 is not in the project at all; inventory 12, files 78, 331, 601, 630, 985, 1169, 1528, 1698.)
