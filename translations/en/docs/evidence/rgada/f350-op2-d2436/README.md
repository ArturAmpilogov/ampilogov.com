# РГАДА, f. 350, op. 2, d. 2436

A working collection of photocopies of five revizskie skazki (census returns) of the odnodvortsy (single-household freeholders) of the village of Bazdyreva in Oryol district. The file belongs to the first revision (census) of 1719.

## Folios Found

- l. 367 — Харитон Филипов сын Анпилогов (Khariton Filipov syn Anpilogov);
- l. 368 — Потап Григорьев сын Анпилогов (Potap Grigoryev syn Anpilogov);
- l. 369 — Гордей Козмин сын Анпилогов (Gordey Kozmin syn Anpilogov);
- l. 370 — Никита Тимофеев сын Анпилогов (Nikita Timofeyev syn Anpilogov);
- l. 371 — Фёдор Меркулов сын Антилогов (Fyodor Merkulov syn Antilogov).

The names above are given as in the published name index. On each of the five folios the corresponding handwritten census return has been found, but its full literal transcription has not yet been made.

## Origin of the Files

- published index: <https://forum.vgd.ru/post/1851/142654/p5604530.htm>;
- open collection of photocopies: <https://disk.yandex.ru/d/beTOHQ7SI7x1RQ>;
- path in the collection: `Орловский уезд/1-я ревизия/РГАДА 350-2-2436`;
- date the working copies were saved: 21 August 2026.

The file numbering in the open collection is offset by five from the archival foliation: file `372.jpg` contains l. 367, `373.jpg` contains l. 368, and so on up to `376.jpg`, which contains l. 371. The correspondence has been checked against the numbers written on the folios.

## Reading Status

These five cards are not yet genealogical Records. For each folio it is necessary to:

1. read the whole separate census return, not just the name from the index;
2. save an exact crop of the whole entry;
3. separate the literal transcription from the modern interpretation;
4. list all family members named in the return as separate mentions.

Until then the folios remain source cards with the original, an exact archival address and a verifiable identity.

## Public Display

The files are kept as research working copies. The cards have `publicDisplay: false`: the open availability of the collection does not amount to permission to republish the images on the site.
