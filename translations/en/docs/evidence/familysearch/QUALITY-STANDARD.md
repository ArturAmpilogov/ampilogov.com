# FamilySearch Image Capture Standard

Old captures are not treated as active evidence until the entry has been recaptured to this standard and has received the status `approved` in `data/genealogy/evidence-quality.json`.

For each entry it is required to:

1. Expand the FamilySearch viewer to full screen.
2. Close the Names/Information panels and hide the image strip at the bottom.
3. Wait for the sharp tiles to load; if the image is blurred, reload the page or change the zoom and wait for it to load again.
4. Save an overall frame showing the image number and the position of the source.
5. Save separate enlarged frames of the name and event, the parents or spouses, and all places mentioned.
6. Separately save witnesses, guarantors, godparents, declarants and signatures, if present.
7. Record the SHA-256 of each file. Public display is forbidden until the rights have been checked separately; local captures serve as reference evidence.

The minimum working frame size is 1728×1080. A full page on its own does not replace the enlarged fragments.
