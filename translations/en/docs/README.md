# Ampilogovs / Anpilogovs / Ampilovs / Anpilovs / Anfilogovs

A book about the history of the name, the surname and the different families of Ampilogovs / Anpilogovs / Ampilovs / Anpilovs / Anfilogovs. The public account covers events up to and including 1950. The chapters are linked to the document catalogue, the profiles and the map.

## The Main Principle

The sources show several geographically and chronologically separate groups of bearers of a similar surname. A similar spelling does not prove kinship, and a presumed migration route does not become a fact without a document about a specific person.

Information about the user's present-day direct family line is not yet included in the book.

## Editorial Rule

The text does not join namesakes into a single tree without a document. Every reconstruction either rests on kinship that is explicitly stated or is clearly marked as a hypothesis. Verified information is accompanied by a document card and a link to the image. Scans from `public/archive/evidence/` and `data/genealogy/evidence-private/` are kept in a private Vercel Blob outside Git; finds without a verified image keep their research status.
