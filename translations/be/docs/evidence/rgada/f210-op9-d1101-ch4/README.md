# РГАДА, ф. 210, воп. 9, спр. 1101, ч. 4

Працоўная фатаграфія дакумента са спісамі белгародскіх служылых людзей,
загінулых, параненых і ўзятых у палон пад Канатопам у 1659 годзе.

Карыстальніцкая расшыфроўка на ВГД называе **Зінова Онпілогава
(Анпілогава)**. Дакладны аркуш не ўказаны. Апублікаваная база DomPredkov
пацвярджае шыфр справы, але не змяшчае гэтага прозвішча ў даступнай табліцы.

## Статус выявы

Файл `pages/forum-photo-full.jpg` — фатаграфія развароту памерам 1936×1936.
Яна занадта размытая для надзейнай лакалізацыі радка, кропа і літаральнай
расшыфроўкі. Выява захавана як арыенцір для замовы архіўнай копіі,
але асобны genealogical Record па ёй не створаны.

## Крыніцы

- расшыфроўка і фатаграфія: <https://forum.vgd.ru/1576/68970/1010.htm?a=stdforum_view&o=>;
- картка корпуса і дакладны шыфр: <https://dompredkov.ru/sluzhilye-lyudi-ranenye-umershie-vzyatye-v-plen-v-1659g-pod-konotopom/>;
- дата захавання працоўнай копіі: 21 жніўня 2026 года.

## Што трэба замовіць

1. імянны або аркушавы паказальнік да часткі 4;
2. поўны аркуш з запісам Зінова;
3. здымак не ніжэй за архіўную раздзяляльнасць;
4. пасля атрымання — кроп усяго самастойнага запісу і літаральную
   расшыфроўку без аднаўлення неразборлівых слоў па здагадцы.
