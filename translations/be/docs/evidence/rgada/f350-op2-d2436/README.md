## Статус чытання

Гэтыя пяць картак пакуль не з'яўляюцца genealogical Records. Для кожнага аркуша трэба:

1. прачытаць усю самастойную рэвізскую казку, а не толькі імя з паказальніка;
2. захаваць дакладны кроп усяго запісу;
3. аддзяліць літаральную расшыфроўку ад сучаснай інтэрпрэтацыі;
4. пералічыць усіх названых у казцы членаў сям'і асобнымі згадкамі.

Да гэтага аркушы застаюцца карткамі крыніц з арыгіналам, дакладным архіўным адрасам і правяральнай асобай.
