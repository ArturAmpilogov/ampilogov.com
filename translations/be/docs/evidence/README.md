# Фотакопіі крыніц

Тут захоўваюцца фотакопіі, на якіх грунтуюцца карткі `records/`.

## Структура

```text
evidence/
  rgada/
    f181-op2-d120/
      0060.jpg
  publications/
    ruslang/
      etymology-1971/
        13-nikonov.pdf
        pages/
          0263.jpg
  dazo/
  gark/
  gia-ko/
```

## Правілы

1. Арыгінальны спампаваны файл захоўваецца без абрэзкі і паляпшэння.
2. Імя каталога змяшчае архіў, фонд, вопіс і справу.
3. Імя файла захоўвае нумар кадра або аркуша.
4. Кадр павінен уключаць кантэкст старонкі; павялічаныя фрагменты можна пакласці побач з суфіксам `-crop`, але яны не замяняюць арыгінал.
5. Для кожнай фотакопіі першаснага дакумента існуе хаця б адна картка `R####`.
6. Навуковыя публікацыі могуць быць далучаныя непасрэдна да запісу ў рэестры крыніц; для ключавой старонкі побач захоўваецца асобная выява.
7. У картцы або рэестры крыніц указваюцца URL атрымання, архіўны шыфр або бібліяграфічнае апісанне, старонка і дата спампоўвання.
8. Індэкс або картка сайта без выявы не лічыцца фотакопіяй.

## Аддаленыя праглядальнікі: абавязковы камплект

Для Яндекс Архіва і іншых праглядальнікаў, якія не аддаюць зыходны файл напрамую,
кожны выкарыстаны кадр захоўваецца як тры самастойныя выявы:

1. `####-full-view.png` — увесь аркуш або разварот цалкам. На выяве застаецца толькі
   дакумент: без шапкі сайта, панэлі OCR, кнопак, пошукавай выдачы, палос браўзера і іншых
   элементаў інтэрфейсу.
2. `####-header.png` — павялічаная вобласць з загалоўкам кнігі, годам, часткай і назвамі
   граф. Загаловак павінен чытацца без звароту да OCR сайта.
3. `####-target-entry.png` або `####-target-entry-document-*.png` — павялічаны дакладны
   радок з даследаваным прозвішчам, імёнамі, датай, сваяцтвам і статусам. Захоўваецца дастаткова
   суседніх радкоў і граф, каб адназначна ўстанавіць прыналежнасць тэксту патрэбнаму запісу.

Скрыншот старонкі сайта, пошукавай карткі або акна праглядальніка не замяняе ніводзін з
гэтых файлаў. OCR дапушчальны толькі як пошукавая падказка і не павінен трапляць у фотакопію.
Камплект лічыцца правераным толькі пасля візуальнага прагляду ўсіх трох выяў і
запісу іх SHA-256 у адпаведны Record.

## Фарматы

- JPEG або PNG для асобных кадраў;
- PDF дапушчальны для цэлай справы або публікацыі;
- TIFF захоўваецца, калі гэта зыходны фармат архіва;
- вытворныя WebP-файлы для сайта ствараюцца пазней і не замяняюць арыгіналы.

Вялікія справы пры неабходнасці падключаюцца праз Git LFS, але адзінкавыя метрычныя кадры і старонкі захоўваюцца проста ў Git.
