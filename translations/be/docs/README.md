# Ампілогавы / Анпілогавы / Ампілавы / Анпілавы / Анфілогавы

Кніга пра гісторыю імені, прозвішча і розных родаў Ампілогавых / Анпілогавых / Ампілавых / Анпілавых / Анфілогавых. Публічны аповед ахоплівае падзеі да 1950 года ўключна. Раздзелы звязаныя з каталогам дакументаў, профілямі і картай.

## Галоўны прынцып

Крыніцы паказваюць некалькі геаграфічна і храналагічна асобных груп носьбітаў падобнага прозвішча. Падабенства напісання не даказвае сваяцтва, а меркаваны маршрут перасялення не становіцца фактам без дакумента пра канкрэтнага чалавека.

Звесткі пра сучасную прамую сямейную лінію карыстальніка пакуль у кнігу не ўключаюцца.
