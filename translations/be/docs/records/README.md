# Карткі дакументаў

Картка `R####` — адзінае месца, дзе фармулюецца факт з канкрэтнай крыніцы.

## Структура каталогаў

Карткі групуюцца па годзе дакумента:

```text
records/
  1596/
    R0001-pavel-terentev-anfilogov.md
  1850/
  1900/
```

Калі дакладны год невядомы, выкарыстоўваецца каталог дзесяцігоддзя: `records/1850s/`.

## Абавязковыя палі

- ID запісу;
- дата і месца;
- тып дакумента;
- архіўны шыфр;
- людзі з іх `P####`;
- літаральнае напісанне;
- транскрыпцыя;
- нармалізаванае вылучэнне фактаў;
- шлях да фотакопіі;
- што дакумент даказвае;
- чаго дакумент не даказвае;
- ступень упэўненасці і спрэчныя чытанні.

Шаблон знаходзіцца ў [template.md](template.md).
