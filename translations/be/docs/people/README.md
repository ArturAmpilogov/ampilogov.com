# Людзі і профілі

## Чаму патрэбны гібрыд

Адзін вялікі спіс зручны для агляду, але дрэнна падыходзіць для доказаў. Асобны профіль на кожную выпадковую згадку створыць сотні амаль пустых файлаў. Таму выкарыстоўваюцца тры ўзроўні:

1. `people/index-1800-1999.md` — агульны спіс усіх пацверджаных людзей;
2. `people/profiles/` — асобныя профілі толькі для людзей з некалькімі дакументамі, варыянтамі імені або спрэчным атаясамленнем;
3. `records/` — карткі першасных дакументаў, на якіх грунтуюцца ўсе факты.

## Ідэнтыфікатары людзей

Кожнаму чалавеку прысвойваецца стабільны код `P####`. Код не кадуе дату, месца або прозвішча: гэтыя звесткі могуць удакладняцца, а ідэнтыфікатар павінен заставацца ранейшым.

Новы чалавек з'яўляецца ў рэестры толькі пасля дадання хаця б адной пацверджанай карткі `R####` з фотакопіяй.

## Калі ствараць асобны профіль

Профіль ствараецца, калі:

- ёсць два і больш дакументаў;
- прозвішча або імя запісаныя ў розных формах;
- ёсць аднайменныя людзі, якіх важна адрозніваць;
- дакументальна названыя муж або жонка, дзеці або бацькі;
- чалавек удзельнічае ў даказаным маршруце перасялення.

Для адзінкавай згадкі дастаткова радка ў агульным рэестры і карткі дакумента.

## Забароненыя скарачэнні даследавання

- не ствараць сваяцтва толькі з супадзення імені па бацьку;
- не зліваць аднайменных людзей;
- не пераносіць дату або месца з чужога дрэва без фотакопіі;
- не лічыць індэкс FamilySearch фотакопіяй;
- не дадаваць жывых людзей без асобнага рашэння пра публікацыю.
