# Профілі людзей

Імя файла: `P####-short-slug.md`.

Профіль змяшчае:

- нармалізаванае імя;
- усе літаральныя варыянты імені і прозвішча;
- толькі пацверджаныя даты і месцы;
- спіс картак дакументаў;
- прама названыя адносіны;
- асобны блок спрэчных атаясамленняў;
- спасылкі на міграцыйныя дасье.

Фактычная транскрыпцыя і фотакопія захоўваюцца не ў профілі, а ў адпаведнай картцы `records/`.
