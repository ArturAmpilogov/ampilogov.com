# Картки документів

Картка `R####` — єдине місце, де формулюється факт із конкретного джерела.

## Структура каталогів

Картки групуються за роком документа:

```text
records/
  1596/
    R0001-pavel-terentev-anfilogov.md
  1850/
  1900/
```

Якщо точний рік невідомий, використовується каталог десятиліття: `records/1850s/`.

## Обов'язкові поля

- ID запису;
- дата й місце;
- тип документа;
- архівний шифр;
- люди з їхніми `P####`;
- буквальне написання;
- транскрипція;
- нормалізоване вилучення фактів;
- шлях до фотокопії;
- що документ доводить;
- чого документ не доводить;
- ступінь упевненості та спірні прочитання.

Шаблон міститься в [template.md](template.md).
