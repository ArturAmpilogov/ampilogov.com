# Переселення та розселення

Розділ перевіряє, як окремі носії прізвища переміщалися між Орловським, Курським, Лівенським, Таврійським і Кримським регіонами.

## Що вже доведено

- **Орловський повіт → Лівенські Щигри:** Аким Іванович **Анпілогов** в особистій сказці 1700 року прямо назвав колишнє помістя в Боздиреві, його насильницьке захоплення та 30 четвертей онука Тита в Щиграх. Оригінал перевірено за лл. 1181–1182 РГАДА, ф. 210, оп. 12, д. 1888.

## Що ймовірне, але потребує прямого документа

- **Курськ → Обоянь:** Сергій Григорович із рідкісним прізвищем з'являється в курській десятні 1636 року та обоянській десятні 1651 року. Треба довести, що це одна людина, і зафіксувати переведення або переселення.

## Що поки є напрямком пошуку

- **Курсько-Орловський регіон → материкова Таврія:** у XIX столітті відомі переселення державних селян із центральночорноземних губерній, а в Мелітопольському повіті з'являються носії прізвища. Конкретну родину-переселенця не встановлено.
- **Материкова Таврія → Крим:** у Сімферополі підтверджено родину Сергія Ампілогова з Рильського повіту за метрикою 1868 року (`FS-3Q9M-CS9N-9FBF`). Її зв'язок із Троїцьким чи Тимошівкою та шлях через материкову Таврію не встановлено.

## Правило

Кожен маршрут отримує окреме досьє. У ньому мають бути:

1. пункт відправлення;
2. пункт прибуття;
3. людина або родина;
4. найпізніший документ у пункті відправлення;
5. найраніший документ у пункті прибуття;
6. документ, що прямо пов'язує ці пункти;
7. альтернативні пояснення.
