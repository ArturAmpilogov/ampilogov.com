# Фотокопії джерел

Тут зберігаються фотокопії, на яких ґрунтуються картки `records/`.

## Структура

```text
evidence/
  rgada/
    f181-op2-d120/
      0060.jpg
  publications/
    ruslang/
      etymology-1971/
        13-nikonov.pdf
        pages/
          0263.jpg
  dazo/
  gark/
  gia-ko/
```

## Правила

1. Оригінальний завантажений файл зберігається без обрізання й поліпшення.
2. Назва каталогу містить архів, фонд, опис і справу.
3. Назва файлу зберігає номер кадру або аркуша.
4. Кадр має охоплювати контекст сторінки; збільшені фрагменти можна покласти поруч із суфіксом `-crop`, але вони не замінюють оригіналу.
5. Для кожної фотокопії первинного документа існує принаймні одна картка `R####`.
6. Наукові публікації можна долучати безпосередньо до запису в реєстрі джерел; для ключової сторінки поруч зберігається окреме зображення.
7. У картці або реєстрі джерел зазначаються URL отримання, архівний шифр або бібліографічний опис, сторінка й дата завантаження.
8. Індекс або картка сайту без зображення не вважається фотокопією.

## Віддалені переглядачі: обов'язковий комплект

Для Яндекс Архіву та інших переглядачів, які не віддають вихідного файлу напряму,
кожен використаний кадр зберігається як три самостійні зображення:

1. `####-full-view.png` — увесь аркуш або розворот цілком. На зображенні залишається лише
   документ: без шапки сайту, панелі OCR, кнопок, пошукової видачі, смуг браузера та інших
   елементів інтерфейсу.
2. `####-header.png` — збільшена ділянка із заголовком книги, роком, частиною та назвами
   граф. Заголовок має читатися без звернення до OCR сайту.
3. `####-target-entry.png` або `####-target-entry-document-*.png` — збільшений точний
   рядок із досліджуваним прізвищем, іменами, датою, спорідненістю та статусом. Зберігається достатньо
   сусідніх рядків і граф, щоб однозначно встановити належність тексту потрібному запису.

Знімок екрана сторінки сайту, пошукової картки чи вікна переглядача не замінює жодного з
цих файлів. OCR допустимий лише як пошукова підказка й не повинен потрапляти до фотокопії.
Комплект вважається перевіреним лише після візуального перегляду всіх трьох зображень і
запису їхніх SHA-256 у відповідний Record.

## Формати

- JPEG або PNG для окремих кадрів;
- PDF допустимий для цілої справи чи публікації;
- TIFF зберігається, якщо це вихідний формат архіву;
- похідні WebP-файли для сайту створюються пізніше й не замінюють оригіналів.

Великі справи за потреби підключаються через Git LFS, але поодинокі метричні кадри та сторінки зберігаються просто в Git.
