# РГАДА, ф. 210, оп. 9, д. 1101, ч. 4

Робоча фотографія документа зі списками бєлгородських служилих людей,
загиблих, поранених і взятих у полон під Конотопом 1659 року.

Користувацьке розшифрування на ВГД називає **Зінова Онпілогова
(Анпілогова)** («Зинова Онпилогова (Анпилогова)»). Точного аркуша не вказано. Опублікована база DomPredkov
підтверджує шифр справи, але не містить цього прізвища в доступній таблиці.

## Статус зображення

Файл `pages/forum-photo-full.jpg` — фотографія розвороту розміром 1936×1936.
Вона надто розмита для надійної локалізації рядка, кропа й буквального
розшифрування. Зображення збережено як орієнтир для замовлення архівної копії,
але окремого genealogical Record за ним не створено.

- дата збереження робочої копії: 21 серпня 2026 року.

## Що треба замовити

1. іменний або аркушевий покажчик до частини 4;
2. повний аркуш із записом Зінова;
3. знімок не нижче архівної роздільності;
4. після отримання — кроп усього самостійного запису та буквальне
   розшифрування без відновлення нерозбірливих слів навздогад.
