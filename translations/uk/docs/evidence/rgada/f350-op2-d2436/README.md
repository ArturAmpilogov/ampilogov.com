## Статус прочитання

Ці п'ять карток поки не є genealogical Records. Для кожного аркуша треба:

1. прочитати всю самостійну ревізьку сказку, а не лише ім'я з покажчика;
2. зберегти точний кроп усього запису;
3. відокремити буквальне розшифрування від сучасної інтерпретації;
4. перелічити всіх названих у сказці членів родини окремими згадками.

Доти аркуші залишаються картками джерел з оригіналом, точною архівною адресою та особою, яку можна перевірити.
