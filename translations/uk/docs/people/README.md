# Люди та профілі

## Чому потрібен гібрид

Один величезний список зручний для огляду, але погано пасує для доказів. Окремий профіль на кожну випадкову згадку створить сотні майже порожніх файлів. Тому використовуються три рівні:

1. `people/index-1800-1999.md` — загальний список усіх підтверджених людей;
2. `people/profiles/` — окремі профілі лише для людей із кількома документами, варіантами імені або спірним ототожненням;
3. `records/` — картки первинних документів, на яких ґрунтуються всі факти.

## Ідентифікатори людей

Кожній людині присвоюється стабільний код `P####`. Код не кодує дати, місця чи прізвища: ці відомості можуть уточнюватися, а ідентифікатор має залишатися незмінним.

Нова людина з'являється в реєстрі лише після додавання принаймні однієї підтвердженої картки `R####` із фотокопією.

## Коли створювати окремий профіль

Профіль створюється, якщо:

- є два й більше документів;
- прізвище або ім'я записано в різних формах;
- є однойменні люди, яких важливо розрізняти;
- документально названо подружжя, дітей або батьків;
- людина бере участь у доведеному маршруті переселення.

Для поодинокої згадки достатньо рядка в загальному реєстрі та картки документа.

## Заборонені скорочення дослідження

- не встановлювати спорідненість лише через збіг по батькові;
- не зливати однойменних людей;
- не переносити дату чи місце з чужого дерева без фотокопії;
- не вважати індекс FamilySearch фотокопією;
- не додавати живих людей без окремого рішення про публікацію.
