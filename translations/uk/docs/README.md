# Ампілогови / Анпілогови / Ампілови / Анпілови / Анфілогови

Книга про історію імені, прізвища та різних родів Ампілогових / Анпілогових / Ампілових / Анпілових / Анфілогових. Публічна розповідь охоплює події до 1950 року включно. Розділи пов'язані з каталогом документів, профілями та мапою.

## Головний принцип

Джерела показують кілька географічно й хронологічно відокремлених груп носіїв схожого прізвища. Схожість написання не доводить спорідненості, а гаданий маршрут переселення не стає фактом без документа про конкретну людину.

Відомості про сучасну пряму родинну лінію користувача поки що до книги не включено.

## Редакційне правило

Текст не з'єднує однофамільців в одне дерево без документа. Кожна реконструкція або спирається на прямо назване родство, або явно позначена як гіпотеза. Перевірені відомості супроводжуються карткою документа й посиланням на зображення. Скани з `public/archive/evidence/` і `data/genealogy/evidence-private/` зберігаються в приватному Vercel Blob поза Git; знахідки без перевіреного зображення зберігають свій дослідницький статус.
