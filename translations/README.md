# Переводы сайта

Исходный язык — русский. Переводы: английский (`en`), украинский (`uk`),
белорусский (`be`). Русские адреса остаются без префикса (`/records`),
остальные языки живут под `/en/…`, `/uk/…`, `/be/…`.

## Что где лежит

| Что | Где | Если перевода нет |
| --- | --- | --- |
| Интерфейс (меню, фильтры, подписи, виджеты глав) | `defineCopy(...)` рядом с компонентом, общие строки — `src/i18n/messages.ts` | TypeScript не соберётся: у всех языков одинаковый набор ключей |
| Главы и другие страницы из `docs/` | `translations/<locale>/docs/<тот же путь>.md` | показывается русский текст с пометкой, страница закрыта от индексации |
| Описания глав, периоды, группы | `src/lib/chapter-meta.translations.ts` | русский текст |
| Карточки записей | `translations/<locale>/records/<sourceId>.json` | ссылки ведут на русскую карточку |
| Карточки людей | `translations/<locale>/people/<personId>.json` | ссылки ведут на русскую карточку |

## Главы (`docs/`)

Перевод повторяет структуру оригинала: те же строки `{{TOKEN}}`, адреса ссылок,
коды `[S-…]`, уровни заголовков. Цитаты из документов остаются в оригинале,
перевод даётся рядом.

```bash
pnpm i18n:check           # структура и устаревшие переводы
pnpm i18n:check --stamp   # после обновления перевода: отметить его актуальным
```

Если русский текст главы изменился, `pnpm i18n:check` покажет перевод как
устаревший.

## Карточки

Карточка строится из русских данных, логика страницы работает с русскими
значениями. Файл перевода — словарь «русская строка → перевод», который
применяется только при выводе. Если русские данные поменялись, старая строка
перестаёт совпадать и новый текст показывается по-русски, пока его не
переведут: устаревший перевод никогда не покажет старые факты. Буквальная
расшифровка документа не переводится.

```bash
pnpm i18n:card en records <sourceId>      # создать/обновить файл со всеми строками карточки
pnpm i18n:card uk people <personId>
pnpm i18n:card en records --status        # сколько строк переведено
```

Пустое значение оставляет русский текст. Скрипт сам обновляет
`src/i18n/card-translations.json` (список переведённых карточек): по нему
сайт решает, вести ли ссылку на `/en/records/<id>` или на русскую карточку, и
какие страницы карточек собирать для языка. Манифест также пересобирается
перед `dev` и `build`.
