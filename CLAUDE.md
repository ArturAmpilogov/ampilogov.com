# Обязательные правила охвата исследования

Перед работой с генеалогическими данными соблюдать следующие правила:

- Публичная граница — 1950 год включительно. События и Records после 1950 года не выводить в Records, People и на карте.
- Публичные профили создавать только для Ампилоговых / Анпилоговых / Онфилоговых / Анфилоговых / Ампиловых / Онпилоговых и подтверждённых вариантов этого фамильного ряда.
- Людей других фамилий сохранять в буквальной расшифровке, `mentions`, описании и контексте источника, но не создавать для них отдельные публичные профили и ссылки на профили.
- Карта показывает только места, события и переселения носителей исследуемого фамильного ряда.
- При сомнительной фамилии сначала документировать чтение и доказательства в Record; не создавать профиль или маршрут автоматически.
- Не удалять первичные данные ради публичного фильтра. Канонические подробные правила находятся в `AGENTS.md` и обязательны для этой работы.
- По умолчанию проводить быструю целевую проверку. Полную `next build` запускать только перед merge/deploy, по явной просьбе или когда изменение нельзя надёжно проверить целевыми тестами.
