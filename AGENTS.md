# Обязательные правила охвата исследования

Эти правила действуют для всех агентов, которые добавляют или меняют генеалогические данные, Records, профили людей, карту и страницы книги.

1. Публичная временная граница исследования — **по 1950 год включительно**. События и Records с датой после 1950 года не выводить в публичных каталогах, профилях и на карте. Исходные расшифровки можно сохранять в данных как исследовательский материал, но не включать в публичное ядро сайта.
2. Отдельные профили создавать и публиковать только для носителей исследуемого фамильного ряда: Ампилогов, Анпилогов, Онфилогов, Анфилогов, Ампилов, Онпилогов и документированных орфографических/OCR-вариантов этого ряда.
3. Людей других фамилий — супругов, восприемников, свидетелей, священников, поручителей, соседей и должностных лиц — сохранять внутри буквальной расшифровки, `mentions`, современного чтения и исторического контекста. Не создавать для них отдельные публичные профили и не давать ссылки на профиль.
4. Карта показывает только события, места, наблюдения и переселения носителей исследуемого фамильного ряда. Другие участники документа могут оставаться в тексте карточки, но не должны создавать собственные точки, маршруты или картографические профили.
5. При сомнительной фамилии не расширять публичное ядро автоматически. Сначала сохранить чтение и аргументацию в Record; профиль и карту добавлять только после подтверждения связи с исследуемым фамильным рядом.
6. Эти ограничения реализовывать общими фильтрами представления. Не удалять ценную первичную расшифровку только потому, что запись или участник не входят в публичный охват.

## Режим проверки

- По умолчанию использовать быстрый цикл: `pnpm exec tsc --noEmit`, `npm run genealogy:audit`, `git diff --check` и браузерная проверка только изменённых разделов.
- Не запускать многоминутную полную `next build` после каждого изменения.
- Полную production-сборку делать перед merge/deploy, по явной просьбе пользователя или после рискованного изменения маршрутизации/статической генерации, когда целевые проверки недостаточны.
